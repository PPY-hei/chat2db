# 组管理页面 - 编辑组信息功能

## 功能说明

在"连接组管理"页面中，为 **Owner** 角色添加了编辑组名称和描述的功能。

## 新增功能

### 1. 编辑按钮
- 位置：组信息卡片右上角
- 权限：仅 Owner 可见
- 图标：编辑图标（EditOutlined）

### 2. 编辑模式
点击"编辑"按钮后，卡片内容切换为编辑表单：

**表单字段**：
- **组名称**（必填）：修改组的名称
- **描述**（可选）：修改组的描述信息

**操作按钮**：
- **保存**：提交修改
- **取消**：放弃修改，恢复显示模式

### 3. 权限控制
- 只有 **Owner** 角色可以看到编辑按钮
- Admin、Editor、Viewer 角色无法编辑组信息

## 使用步骤

1. 打开"连接组管理"页面
2. 选择一个你是 Owner 的组
3. 点击组信息卡片右上角的"编辑"按钮
4. 修改组名称或描述
5. 点击"保存"提交修改
6. 或点击"取消"放弃修改

## 技术实现

### 状态管理
```typescript
const [editing, setEditing] = useState(false);  // 是否处于编辑模式
const [saving, setSaving] = useState(false);    // 是否正在保存
const [editForm] = Form.useForm();              // 编辑表单
```

### 核心函数

**startEdit()**：进入编辑模式
- 将当前组信息填充到表单
- 设置 `editing = true`

**cancelEdit()**：取消编辑
- 重置表单
- 设置 `editing = false`

**submitEdit()**：提交修改
- 验证表单
- 调用 API 更新组信息
- 刷新组列表
- 退出编辑模式

### API 调用
```typescript
await api.updateGroup(currentGroup.id, {
  name: v.name,
  description: v.description,
});
```

## 验证规则

- **组名称**：必填，不能为空
- **描述**：可选

## 错误处理

- 表单验证失败：显示字段错误提示
- API 调用失败：显示错误消息
- 网络错误：显示"修改失败"提示

## 用户体验优化

1. **即时反馈**：保存成功后显示"修改成功"提示
2. **加载状态**：保存时按钮显示 loading 状态
3. **表单保留**：取消编辑后，表单数据会被重置
4. **权限隐藏**：非 Owner 用户看不到编辑按钮

## 注意事项

1. **权限检查**：只有 Owner 可以编辑
2. **数据同步**：修改后会自动刷新组列表
3. **编辑状态**：切换组时会自动退出编辑模式
4. **表单验证**：组名称不能为空
