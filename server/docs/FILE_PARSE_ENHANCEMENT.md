# 文件解析增强说明

## 问题

**之前**：只预览前 5 行数据，AI 可能因为数据不全而无法准确回答问题。

**现在**：提供完整的数据统计信息 + 智能采样预览。

## 新增功能

### 1. 每列统计信息

**数值型列**：
- 非空值数量
- 空值数量
- 唯一值数量
- 最小值
- 最大值
- 平均值

**文本型列**：
- 非空值数量
- 空值数量
- 唯一值数量
- 最常见的值（前 3 个）

### 2. 智能数据预览

- **前 10 行**：了解数据开头
- **中间 5 行**：了解数据中段（如果总行数 > 20）
- **最后 5 行**：了解数据结尾（如果总行数 > 20）

这样 AI 可以看到数据的整体分布，而不只是开头。

## 现在 AI 可以准确回答的问题

### 1. 数据范围问题
**问**：工资范围是多少？  
**答**：工资范围从 11,000 到 23,000，平均工资 16,180。

### 2. 数据分布问题
**问**：有哪些部门？  
**答**：有 3 个部门：技术部、销售部、管理部。

### 3. 唯一值问题
**问**：有多少个不同的城市？  
**答**：数据中有 25 个唯一的城市值（每个员工的城市都不同）。

### 4. 数据质量问题
**问**：数据完整吗？有空值吗？  
**答**：所有列都没有空值，数据完整。

### 5. 精准 SQL 生成
**问**：查询技术部工资最高的 3 个人  
**答**：
```sql
SELECT name, salary, city
FROM employees
WHERE department = '技术部'
ORDER BY salary DESC
LIMIT 3;
```

AI 知道：
- 列名是 `department` 不是 `dept`
- 值是 `'技术部'` 不是 `'tech'`
- 有 `name`, `salary`, `city` 等列可用

## 性能考虑

- **小文件（< 1000 行）**：全量读取，完整统计
- **大文件（> 1000 行）**：
  - 统计信息仍然准确（遍历所有行）
  - 预览采样：前 10 + 中间 5 + 最后 5 行
  - 避免传递过多数据给 AI
