# 快速开始：测试文件上传功能

## 1. 启动应用

```bash
# 后端
cd /Users/chy/projects/chat2db/server
go run cmd/server/main.go

# 前端（另一个终端）
cd /Users/chy/projects/chat2db/web
npm run dev
```

## 2. 打开浏览器

访问 `http://localhost:5173`（或前端显示的地址）

## 3. 测试步骤

### 步骤 1：创建连接并打开 SQL 编辑器

1. 登录应用
2. 创建或选择一个数据库连接
3. 打开 SQL 编辑器

### 步骤 2：打开 AI 对话

点击工具栏的 **AI** 按钮（或按 `Alt + I`）

### 步骤 3：上传测试文件

点击 **"上传文件（图片/Excel/CSV）"** 按钮，选择：
- `server/docs/test_data.csv`（10 行简单数据）
- 或 `server/docs/test_employees.csv`（25 行员工数据）

上传后会看到文件显示在对话框中。

### 步骤 4：测试问答

#### 测试 1：数据结构
```
问：这个文件有哪些列？
```

**期望回答**：AI 会列出所有列名（如：id, name, age, city, salary, department, join_date）

#### 测试 2：统计信息
```
问：工资范围是多少？平均工资多少？
```

**期望回答**：AI 会给出准确的最小值、最大值和平均值

#### 测试 3：数据分布
```
问：有哪些部门？每个部门有多少人？
```

**期望回答**：AI 会列出所有部门（技术部、销售部、管理部）

#### 测试 4：SQL 生成
```
问：查询技术部工资最高的 3 个人
```

**期望回答**：生成正确的 SQL，使用实际的列名和值
```sql
SELECT name, salary, city
FROM employees
WHERE department = '技术部'
ORDER BY salary DESC
LIMIT 3;
```

#### 测试 5：数据质量
```
问：数据完整吗？有空值吗？
```

**期望回答**：AI 会告诉你每列的空值情况

## 4. 验证要点

✅ **文件上传成功**：看到文件列表显示  
✅ **数据自动解析**：AI 能回答关于列名的问题  
✅ **统计信息准确**：AI 给出的数值与实际一致  
✅ **SQL 生成正确**：使用实际的列名和值，不是猜测的  

## 5. 调试技巧

### 查看后端日志
后端会输出解析结果，可以看到 `data_summary` 的内容

### 查看网络请求
浏览器开发者工具 → Network → 找到 `/api/ai/upload` 请求  
查看 Response，确认 `data_summary` 字段有内容

### 查看 AI 请求
Network → 找到 `/api/ai/chat` 请求  
查看 Request Payload 中的 `prompt`，确认包含了文件数据摘要

## 6. 常见问题

### Q: 上传后 AI 还是不知道数据内容？
**A**: 检查：
1. 后端日志是否有解析错误
2. 网络请求中 `data_summary` 是否为空
3. AI 请求的 prompt 是否包含数据摘要

### Q: 解析很慢？
**A**: 大文件（> 10000 行）解析需要时间，这是正常的。统计信息需要遍历所有行。

### Q: Excel 文件解析失败？
**A**: 确保：
1. 文件格式正确（.xlsx 或 .xls）
2. 文件没有密码保护
3. 第一行是表头
