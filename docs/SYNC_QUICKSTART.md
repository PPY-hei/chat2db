# 数据库同步功能 - 快速开始

## 功能简介

Chat2DB 现已支持两种数据库同步任务：

1. **表结构同步**：自动对齐源表和目标表的字段、索引等结构
2. **表数据同步**：批量复制源表数据到目标表

## 快速使用

### 步骤 1：启动应用

```bash
# 后端
cd server
go run cmd/server/main.go

# 前端
cd web
npm run dev
```

### 步骤 2：创建同步任务

1. 登录系统
2. 打开任务列表（点击顶部菜单）
3. 点击"新建同步"按钮
4. 选择任务类型：
   - **表结构同步**：同步表定义（字段、索引）
   - **表数据同步**：同步表数据
5. 配置源和目标：
   - 选择连接组
   - 选择源连接 → 数据库 → Schema → 表
   - 选择目标连接 → 数据库 → Schema → 表
6. 提交任务

### 步骤 3：监控任务

- 任务列表会显示实时进度
- 状态：排队中 → 执行中 → 成功/失败
- 可以随时取消正在执行的任务

## 示例场景

### 场景 1：开发环境同步到测试环境

```
源：dev_db.public.users
目标：test_db.public.users
任务类型：表结构同步 + 表数据同步
```

1. 先执行表结构同步，确保表结构一致
2. 再执行表数据同步，复制数据

### 场景 2：数据库迁移

```
源：old_server.production.orders
目标：new_server.production.orders
任务类型：表结构同步 + 表数据同步
```

### 场景 3：表结构变更同步

```
源：master_db.public.products（已更新）
目标：replica_db.public.products（旧版本）
任务类型：表结构同步
```

## 注意事项

### 表结构同步
- ✅ 会创建不存在的表
- ✅ 会添加缺失的列
- ✅ 会修改列类型
- ✅ 会创建缺失的索引
- ❌ 不会删除多余的列或索引

### 表数据同步
- ✅ 批量插入，性能优秀
- ✅ 自动匹配列名
- ❌ 不会清空目标表（追加模式）
- ❌ 如有唯一约束冲突会失败

## 支持的数据库

- PostgreSQL
- MySQL

## 常见问题

**Q: 数据同步会清空目标表吗？**  
A: 不会，数据同步是追加模式。如需清空，请手动执行 `TRUNCATE TABLE`。

**Q: 可以跨数据库类型同步吗（如 PostgreSQL → MySQL）？**  
A: 当前版本不支持，源和目标必须是相同类型的数据库。

**Q: 表结构同步会删除目标表多余的列吗？**  
A: 不会，仅添加和修改，不删除。

**Q: 数据同步失败了怎么办？**  
A: 查看任务详情中的错误信息，常见原因：
- 唯一约束冲突
- 数据类型不兼容
- 目标表不存在（先执行表结构同步）

**Q: 可以同步大表吗？**  
A: 可以，采用批量处理（1000 行/批），支持任意大小的表。

**Q: 如何取消正在执行的任务？**  
A: 在任务列表中点击"取消"按钮，任务会在下一个检查点停止。
